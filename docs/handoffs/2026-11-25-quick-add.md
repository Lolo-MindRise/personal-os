# Handoff 2026-11-25: Quick add and category suggestion (plan 0003, task 07)

Branch `agent/0003/07-quick-add` (from `integration/0003-data-safety-and-daily-use`).

## Done
- Key N opens the new-movement panel from any screen (`QuickAdd.tsx`, mounted once in `App.tsx`).
  Decision is the pure `shouldOpenQuickAdd` (`quickAdd.ts`): not in input/textarea/select/
  contenteditable, not with Ctrl/Alt/Meta, not on repeat or while composing, not when a
  `[role=dialog]` is open, not when focus is in the undo toast. Focus returns to the opener via
  `SidePanel` (existing behaviour).
- The "Añadir movimiento" button of Movimientos and a new sidebar button "Nuevo movimiento N" open
  the same panel (events in `quickAdd.ts`); `title` and `aria-keyshortcuts` carry the hint. Saving
  dispatches `MOVEMENT_SAVED_EVENT`; `MovementsPage` reloads through `useMovementSaved`. Other
  screens show a polite "Movimiento guardado." for 5 s. Edit and confirm still use the page's own
  panel; its add mode is now unused (left in place, not removed).
- Suggestion: `GET /api/movements/suggest-category?kind=income|expense&concept=...`
  (`suggestApi.ts`) reads movements only through `liveMovements()`, same kind, newest first,
  limit `SUGGEST_SCAN_LIMIT = 2000` (`src/shared/suggestCategory.ts`). Similarity: exact
  normalised concept first (lowercase, no accents, punctuation and digits dropped), else a shared
  word of 3+ letters; most frequent category, tie to the most recent (date, then id).
  Repayment gets no suggestion (400 from the endpoint, none requested by the UI).
- UI: debounced 300 ms, "Sugerencia: X" + "Usar" in a polite live region in the form. Never
  applied on its own, on blur or on save; hidden when the concept or kind changed since the
  answer, or when that category is already chosen.
- Tests: `suggestCategory.test.ts`, `suggestApi.test.ts`, `quickAdd.test.ts`, the endpoint in the
  `trashEquivalence.test.ts` table, `e2e/quick-add.spec.ts` (N on Informes, suggestion, Usar,
  kind change, Ctrl+N, save from Movimientos; data removed permanently in `finally`).
- Glossary: Nuevo movimiento, Sugerencia, Usar.
