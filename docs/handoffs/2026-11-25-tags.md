# Handoff 2026-11-25: Tags (plan 0002, task 04)

Branch `agent/0002/04-tags` (from `integration/0002-insights-and-accounts`).

## Done
- Tables `tags` (`name`, unique `name_key` = trimmed lower-case name) and `movement_tags` (many to
  many, both real foreign keys, `ON DELETE CASCADE`). Migration `0008_odd_may_parker.sql`: two
  CREATE TABLE and one index, generated and reviewed (no DROP, no rebuild). Test: every existing
  row (accounts, categories, movements, transfers) survives; constraints and cascades.
- API: `GET /api/tags` (with movement counts), `PATCH /api/tags/:id` (rename, 409 on a clash
  ignoring case/spaces; changing only the case of its own name is allowed), `DELETE /api/tags/:id`
  (only links go). Movements accept `tags: string[]` (names; created on the fly, max 10, 30 chars);
  omitted on PATCH = unchanged, `[]` = clear. Every `MovementDto` carries `tags` (names, sorted).
- Search: `tagIds=1,3` (comma list). A movement must carry **all** known selected tags
  (conservative choice); unknown ids are ignored; malformed lists are a 400.
- URL: key `tag=1,3` in `movementSearch.ts` (serialise/parse/panel fields/description). Unknown ids
  are ignored by the server, and not listed in the filter description.
- UI: tag box in the movement form (Enter or comma adds, text left in the box counts on save,
  datalist suggestions; hidden when confirming a fixed item), chips in the monthly list and in the
  search results, tag checkboxes in the filter panel, new "Marcas" screen under Ajustes (rename,
  delete, link to the filtered search).
- CSV export gains a last column "Marcas" (names joined by ", "); existing columns unchanged.
- Glossary: tags are called "marca/marcas" (never "etiqueta", which stays banned for categories).
  Data model updated.
- Tests: migration, API, form/filter/URL/list/page helpers, e2e `tags.spec.ts` (tag, filter,
  reload keeps filter, rename, delete keeps movements); navigation e2e lists Marcas.

## Decisions taken
- "marca" in the UI and `tags` in code and API.
- Tag names are unique by JS lower-casing in `name_key` (SQLite `lower()` only folds ASCII).
- The confirm-fixed-item flow has no tags (the box is hidden there); tag the movement afterwards.
- `src/web/router.ts` got `'tags'` in `VIEW_IDS` (needed for the route, like `accounts` before).
